# Supermart Grocery Sales Dashboard

## Project Overview

This project is an interactive grocery sales dashboard created using Microsoft Excel. The dashboard analyzes sales and profit performance across different regions, categories, cities, and time periods.

## Objective

The main objective of this project is to analyze grocery sales data and provide useful insights into sales and profitability using Excel dashboards, pivot tables, charts, and slicers.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Excel formulas
* Data analysis and visualization

## Key Analysis

The dashboard analyzes:

* Total Sales
* Total Profit
* Sales by Region
* Profit by Region
* Sales by Category
* Sales trends over time
* Regional and category performance

## Dashboard

The final dashboard provides an interactive view of the grocery sales data and allows users to filter the analysis using slicers.
